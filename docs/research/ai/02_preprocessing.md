## 1. 타깃 이상치 임계 (M6.A4)

| 후보 | 결과 |
|---|---|
| log1p 스케일 IQR k=3.0 | 채택. 파일럿 데이터 기준 개입 0건 |
| raw 스케일 IQR | 기각 — 실수요 오탐 |
| IQR k=1.5 | 기각 — 실수요 오탐 |
| P1/P99 캡 | 기각 — 실수요 오탐 |

각 학습 배치의 train 구간에 fit하고 경계 밖 값은 경계로 캡(winsorize)한다. 피처(기상 극값 등)는 실측이므로 별도 처리하지 않는다.

## 2. 결측값 처리 후보 (M6.A4)

- 기상 NA → 캘린더 선형 보간. 과거 실측 구간이라 방향 제약이 없다.
- 유동인구(월간) → 전월 값 ffill + staleness 플래그. **선형 보간은 금지** — 누락 월의 다음 달 값을 참조하게 되어 서빙 시점에 알 수 없는 정보가 섞인다(누수).
- 타깃 lag·rolling 워밍업 NaN → 트리 모델은 네이티브 NaN 유지, 선형·통계 모델만 core lag(lag1·roll7·lag_dow) 완비 행 사용.

## 3. 검증 분할 (M6.A4)

월 단위 walk-forward를 채택했다. 검증 fold는 영업일 10일 이상인 캘린더 월, train은 해당 월 이전 전체 영업일, 최종 fold는 test로 봉인한다. 휴업 월은 규칙상 자동 배제된다.

매장별 단일 시계열이므로 무작위 K-fold는 쓸 수 없다.

## 4. 피처 ablation

유동인구 피처는 ablation에서 +1.2% 악화로 모델 1군에서 제외했다.
