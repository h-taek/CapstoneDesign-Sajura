### 2-1. 세담터 — 세종시 자체 빅데이터 플랫폼 ✅ 핵심 (세종 전용)

| 항목 | 내용 |
|------|------|
| 출처 | [세담터 — 세종특별자치시 빅데이터 플랫폼](https://www2.sejong.go.kr/bigdata/) |
| 제공 데이터 | 유동인구 분석, 소비패턴 분석 등 **총 385종** |
| 조치원 포함 | ✅ 확인됨 (조치원 지역 빅데이터 분석 사례 존재) |
| 무료 여부 | **무료** (회원가입 후 이용 신청) |
| 제공 방식 | Open API + 파일 다운로드 |

> **(37차, 2026-07-27) 재검증** — 정상 운영 확인. 2025-12 개편으로 '데이터세종' 메뉴에 유동인구·소비 데이터가 전면 배치됨. ⚠️ 사이트 TLS 인증서 체인이 불완전해 일부 HTTP 클라이언트에서 검증 실패(`curl -k` 정상).
> **(37차 후속) 결과: 시간대별 유동인구 데이터셋 확보 실패 → 대체 데이터로 전환** — 세담터에서 조치원 시간대별 유동인구를 찾지 못해, **세종시 행정동별 월간 생활·유동인구 리포트**(조치원읍_YY_MM.xlsx, 2025-01~2026-05)를 확보해 사용한다. 월 단위 해상도라 일별 피처 조인 시 전월(lag) 값을 쓴다. 적재: `AI/data_prep/people_load.py`, 현황: `AI/data/README.md`.

> **서울 생활인구 API(data.seoul.go.kr)는 세종에서 사용 불가.** 세종 유동인구는 세담터를 통해 확보해야 한다.

## 4. 학사일정 (조치원 특화) ✅ MVP 포함 강력 권장

조치원 홍익대 상권은 **학기 중 vs 방학** 유동인구 편차가 크다. 학사일정은 무료이며 예측력이 높을 수 있어 필수 피처로 추가 권장.

| 항목 | 내용 |
|------|------|
| 출처 | 홍익대학교 통합 홈페이지 [학사일정](https://www.hongik.ac.kr/kr/education/academic-schedule.do) (서울·세종 공통 학사일정) |
| 수집 방법 | **(37차 정정)** 수동 정리 CSV(`AI/data/manual/academic_calendar.csv`, 검수제) — 자동 파싱은 Phase 8에서 Playwright로 |
| 제공 데이터 | 개강일, 종강일, 시험 기간, 방학 기간, 축제 일정 등 |
| 갱신 주기 | 학기별 (연 2회) |
| 무료 여부 | **무료** |
| 피처 예시 | `is_semester` (학기 중 여부), `is_exam_week`, `days_until_vacation` |

> **(37차, 2026-07-27) 수집 방법 정정** — 구 세종캠퍼스 도메인(`sejong.hongik.ac.kr/.../calendar_*.html`)은 통합 사이트로 302 리다이렉트되고, 통합 학사일정 페이지는 JS 동적 렌더링이라 requests+BeautifulSoup 단순 파싱이 불가. 갱신이 연 2회뿐이라 MVP는 **수동 정리 CSV(검수제)**로 확정, 브라우저 자동화 수집은 운영 배치(Phase 8)로 이월.

## 8. 다음 단계

1. 세담터 회원가입 및 유동인구 API 이용 신청 → 제공 형식·갱신 주기 확인
2. 소상공인 상가(상권)정보 CSV 다운로드 → 조치원읍 필터링 후 DB 적재
3. 홍익대 세종캠퍼스 학사일력 파싱 로직 구현 (n8n 또는 Python)
4. 기상청 API ServiceKey 발급 → n8n HTTP 노드 연결 테스트
5. 확정된 데이터 소스를 `docs/spec/11_ai_spec.md` §4 입력 데이터 표에 반영
