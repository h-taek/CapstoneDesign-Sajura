# 쿠팡 페이지 실동작 확인

> 대상: 사주라 확장이 쿠팡에서 읽고 수행해야 하는 동작(`04_fe.md` §12)이 실제 페이지에서 가능한지. 2026-10-28, 데스크톱 Chrome. §1~§4는 비로그인 상태, §5는 로그인 상태에서 확인했다.

---

## 1. 검색 결과 페이지 (`/np/search?q=<검색어>`)

- 상품 카드는 `li.ProductUnit_productUnit__Qd6sv`다. 클래스 이름 뒤 해시(`__Qd6sv`)는 빌드마다 바뀔 수 있는 CSS 모듈 형식이다.
- 카드 링크는 `/vp/products/<productId>?itemId=<itemId>&vendorItemId=<vendorItemId>&…`다. 카드의 `data-id` 속성 값은 `vendorItemId`와 같다(60개 중 60개).
- 카드 글자에 상품명(용량·개수 포함), 취소선 가격, 할인율, 표시 가격, 단위가격 표시가 있다. 예: '구이용 삼겹살, 1kg, 2개 / 38,500원 / 48% / 19,900원 / (100g당 995원)'.
- 취소선 가격 요소의 클래스에 `fw-line-through`가 있다.
- 단위가격 표시는 표시 가격 기준이다. 예: 29,500원 ÷ (500g × 4) × 100g = 1,475원과 표시 '(100g당 1,475원)'이 일치한다.
- 한 페이지 60개 카드 중 광고 카드가 있고('광고' 글자), 같은 상품이 광고와 일반 결과에 두 번 나온다(삼겹살: 60개 중 고유 `vendorItemId` 54개, 광고 10개).
- '와우 가입 쿠폰'처럼 표시 가격 아래에 별도 금액이 붙는 카드가 있다(삼겹살 60개 중 5개).
- 취소선 가격이 표시 가격보다 크게 높은 카드가 있다. 예: '[10박스한정] 착한가격 삼겹살 HACCP인증 구이용, 1박스, 1kg'(`productId` 9765605796, `vendorItemId` 96147550099) 취소선 67,200원, 할인율 75%, 표시 가격 16,800원. 같은 상품 2kg은 111,200원 → 27,800원.
- 할인 표시 글자는 '할인'·'쿠폰할인'·'와우쿠폰할인' 등으로 나뉜다. 위 상품은 '쿠폰할인'이다.
- 로켓프레시 상품 카드에는 `logo_fresh_medium.png` 이미지가 있다(삼겹살 60개 중 4개, 2-3의 모아미트 상품 포함). `alt`는 비어 있다.
- 별점·리뷰 수는 카드의 `[class*="ProductRating_productRating"]` 안에 있다. 별점은 숫자 없이 별 요소로만 그려지고(`ProductRating_fullRating` 1점, `ProductRating_halfRating` 0.5점), 리뷰 수는 '(10,935)'처럼 글자로 있다. 로그인 상태 삼겹살 카드 36개 모두에 있었고, 별점은 4.5가 33개, 5가 3개였다. 같은 상품의 다른 묶음 수량 카드는 리뷰 수가 같다.
- 비로그인 상태의 머리글에는 '로그인' 링크가 있다. 로그인 상태의 머리글은 §5.

## 2. 연속 검색

- 검색 페이지에서 같은 출처 `fetch('/np/search?q=…')`로 다섯 검색어를 연달아 요청했다. 모두 200, 각 약 1.0~1.2초, 응답 HTML 0.8~1.6MB였고 차단·확인 페이지는 없었다.
- 받은 HTML을 `DOMParser`로 읽으면 화면과 같은 상품 카드 60개가 들어 있다. 탭을 열지 않고도 검색 결과를 읽을 수 있다.
- 다섯 번보다 많은 연속 요청과 짧은 간격의 반복은 확인하지 않았다.
- 같은 브라우저에서 약 10분 동안 위 fetch 5회, 상품 페이지 2개 열기, 장바구니 담기 1회, 장바구니 페이지 열기를 한 뒤, 새 탭에서 검색 페이지 주소(`/np/search?q=삼겹살`)를 직접 열자 '요청하신 페이지의 사용권한이 없습니다' 페이지(참조 번호 포함)가 나왔다. 첫 검색 페이지도 같은 방식(주소 직접 열기)으로 열었을 때는 정상이었다. 차단이 주소 직접 접근 때문인지 그 사이 활동이 쌓인 때문인지는 이 관찰로 나눌 수 없다.
- 같은 브라우저에서 쿠팡 첫 화면을 열고 검색창에 입력해 검색하면 정상으로 열렸다. 이때 검색 페이지 주소에는 `channel=user`·`traceId`가 붙는다. 사용자 정정(2026-10-29): 위에서 막힌 것은 잘못된 주소를 넣었기 때문이고, 정상 주소를 직접 열면 막히지 않는다.

## 3. 상품 페이지 (`/vp/products/<productId>?itemId=…&vendorItemId=…`)

- 가격 영역은 `.price-container`이고, `.original-price`에 할인율·취소선 가격, `.final-price`에 표시 가격과 단위가격 표시가 있다.
- 묶음 수량(1개·2개·3개…)이 선택지로 나오는 상품이 있다. 선택지마다 가격이 다르다.
- 로켓프레시 상품(모아미트 삼겹살 1kg)은 비로그인 상태에서 '장바구니 담기' 대신 '로켓와우 신청하기' 버튼만 보인다.
- 판매자 배송 상품(친절정육점 벌집 삼겹살)은 `button.prod-cart-btn`('장바구니 담기')과 `button.prod-buy-btn`('바로구매'), 그 옆 수량 입력칸(`input[type=text]`, 기본값 1)이 있다.

## 4. 장바구니 담기

- 판매자 배송 상품에서 수량 입력칸에 2를 넣고 '장바구니 담기'를 누르자 '상품이 장바구니에 담겼습니다' 팝업이 떴고, 장바구니(`cart.coupang.com/cartView.pang`)에 수량 2·31,300원으로 들어갔다.
- 담기 때 `POST /next-api/order/add-cart`가 200으로 응답했고, 이어서 `GET /n-api/web-adapter/cart-count`가 호출됐다.
- 비로그인 상태에서 담은 장바구니는 로그인하면 계정 장바구니로 합쳐진다(사용자 직접 확인).

## 5. 로그인 상태

- 머리글의 '로그인' 링크가 사라지고 '로그아웃' 링크(`login.coupang.com/login/logout.pang`)와 '<이름> 님' 표시가 나온다. 비로그인 상태의 '로그인' 링크는 `login.coupang.com/login/login.pang`이다.
- 같은 방식(첫 화면 검색창에 '삼겹살' 입력)으로 검색하면 상품 카드가 36개였다(비로그인 60개). 화면 끝까지 내려도 늘지 않았다. 광고 카드 10개를 빼면 26개다.
- 광고를 뺀 26개 중 25개가 로켓프레시 상품이었다(비로그인 50개 중 4개).
- 비로그인 결과와 `vendorItemId`가 겹치는 상품은 4개였다. 그중 1개('미국산 삼겹살 구이용 (냉장), 1개, 1kg')는 표시 가격이 비로그인 15,820원, 로그인 14,990원으로 달랐고 로그인 쪽에 '와우할인' 표시가 붙었다.
- 26개 중 8개에 '와우할인' 또는 '와우쿠폰할인' 표시가 있었다. 비로그인 50개에는 없었다.
- 확인한 계정의 로켓와우 가입 여부는 확인하지 않았다.


## 6. 화면 요소 목록과 스크립트 클릭 (2026-10-28)

확장이 화면을 읽어 LLM에 넘기는 방식의 근거로 Claude in Chrome 도구(요소 트리 `read_page`, 요소 찾기 `find`, 페이지 내 스크립트 실행)로 확인했다. 검색은 첫 화면 검색창에 '계란'을 입력했다.

### 6.1 요소 트리 크기

| 화면 | 전체 요소 트리 | 누를 수 있는 요소만 |
|---|---|---|
| 검색 결과(비로그인, 카드 60개) | 83,677자 | 7,208자 |
| 그중 상품 목록 부분 | 40,793자(카드 1개당 약 680자) | — |
| 상품 페이지(비로그인) | 101,991자 | 3,262자 |

- '누를 수 있는 요소만'으로 거르면 상품 카드 링크에 글자가 붙지 않아 상품명·가격이 빠진다.
- 상품 카드 하나의 요소 트리에는 상품명, 취소선 가격, 할인율, 표시 가격, 단위가격 표시, 도착 예정, 별점(숫자 글자), 리뷰 수, 적립금, 광고 표시('Ad information' 버튼)가 글자로 나온다.
- 로켓프레시 표시(`logo_fresh_medium.png`)는 `alt`가 비어 있어 요소 트리에 나오지 않는다.
- 검색 결과의 상품 링크는 모두 `target="_blank"`다. 스크립트로 링크를 눌렀을 때 도구의 탭 묶음에는 새 탭이 생기지 않았다. 묶음 밖에 열렸는지 팝업 차단에 막혔는지는 확인하지 않았다.
- 장바구니의 상품별 '삭제' 글자는 요소 트리에 없었고 요소 찾기로도 찾지 못했다. 캡처 좌표로 눌러 삭제했다.

### 6.2 스크립트 클릭

- 상품 페이지(판매자 배송 상품, 비로그인)에서 '장바구니 담기' 버튼을 페이지 스크립트의 `click()`으로 누르자 '1,700원 할인받고 담기 완료' 팝업이 뜨고 장바구니 수가 1에서 2로 늘었다. 사람이 누른 클릭이 아닌 이벤트도 담기가 된다.

### 6.3 로그인 상태의 개인정보 위치

첫 화면, 검색 결과, 상품 페이지, 장바구니에서 화면 글자와 `aria-label`·`title`·`alt`·입력칸 값을 전화번호·이메일·주소·'○○님' 모양으로 검사했다(스크립트 제외, 첫 화면 밖에서는 꼬리말도 제외).

| 화면 | 본인 정보 | 그 밖에 걸린 것 |
|---|---|---|
| 첫 화면 | 회원 이름: 머리말 '마이쿠팡' 링크의 `title`('<이름>님 마이쿠팡 바로가기') | 꼬리말의 쿠팡 고객센터 이메일 |
| 검색 결과 | 같은 링크 `title` | 없음 |
| 상품 페이지 | 같은 링크 `title` | 판매자 전화번호·이메일(판매자 정보, 배송·반품 표), '고객님'·'구매회원님' 같은 일반 문구 |
| 장바구니 | 없음 | 없음. 배송지 칸 없음 |

- 주소·전화번호·이메일 모양의 본인 정보는 네 화면에 없었다.
- §5에 적은 머리말의 '<이름> 님' 표시 글자는 이번 검사에서 잡히지 않았다. 검사는 글자 조각 하나 안에서 이름과 '님'이 함께 있어야 잡히므로, 둘이 다른 조각으로 나뉘어 있으면 놓친다. 이 차이는 확인하지 않았다.
- '○○님' 모양 검사는 '고객님' 같은 일반 문구에도 걸린다.
- 주문·결제 화면과 마이쿠팡은 열지 않았다.

### 6.4 스크립트 입력·엔터·수량 (비로그인)

페이지 스크립트로만 조작하고, 결과는 화면 주소와 장바구니 수량으로 확인했다.

| 조작 | 결과 |
|---|---|
| 첫 화면 검색창에 값 넣기(값 설정 후 `input`·`change` 이벤트) + `keydown`·`keypress`·`keyup` 엔터 | 칸에 '두부'가 들어갔지만 검색되지 않음 |
| 같은 상태에서 검색 버튼(`type=submit`) `click()` | '두부' 검색 결과(`/np/search?…&channel=user`)가 정상으로 열림. 차단 페이지 없음 |
| 상품 링크의 `target` 속성을 지우고 `click()` | 같은 탭에서 상품 페이지가 열림. 새 탭 없음 |
| 상품 페이지 수량 칸에 값 넣기(2, `input`·`change`·`blur` 이벤트) 후 '장바구니 담기' | 칸에는 2가 보였지만 장바구니에는 1개가 담김 |
| 수량 버튼 `click()` 두 번 후 '장바구니 담기' | 수량 칸 1 → 3, 장바구니 수량이 3 늘어남(2 → 5) |
| 장바구니 상품별 '삭제'(`div`, 역할 없음) `click()` | 상품이 빠짐. 확인 창 없음 |

- 상품 페이지 수량 칸 옆 버튼 둘의 이름이 실제 동작과 반대다. 위쪽 버튼은 글자가 '수량빼기'인데 누르면 수량이 늘고, 아래쪽 '수량더하기'는 수량 1에서 비활성이다(CJ 행복한 콩 단단한 큰두부 520g 4개, `productId` 8244230770).
- 사람 입력과 같은 방식(Claude in Chrome 키 입력)으로 수량 칸에 2를 치면 칸 값이 2가 되고 '수량더하기' 버튼이 활성으로 바뀌었다. 이 상태로 담기는 하지 않았다.
- 장바구니 상단 숫자는 담긴 상품 종류 수이고 수량 합이 아니다.

### 6.5 상품 고유 ID와 상품 페이지 옵션 (2026-10-29, 비로그인)

상품 페이지 다섯 곳에서 옵션을 바꾸며 주소의 `productId`·`vendorItemId`와 상품 제목(`h1`)을 읽었다.

| `productId` | 옵션 머리글 | 탭(포장 단위) | 목록(그 포장 단위의 개수) |
|---|---|---|---|
| 1444872149 선진포크 한돈 목심 | 중량 × 수량 | 1kg·300g·500g | 1팩~5팩 |
| 988704 해표 카놀라유 | 개당 용량 × 수량 | 250ml·500ml·900ml·1L | 900ml: 1·2·3·6개, 500ml: 2·3·5·8개 |
| 6258806325 국내산 양파 | 중량 × 수량 | 1.2kg·1.5kg·5kg(사진 버튼) | 1·3·5개 |
| 8244230770 CJ 큰두부 | 개당 중량 × 수량 | 520g·800g | 520g: 4·5·6·10개 |
| 9744284590 해표 식용유 | 수량 | 없음 | 1·2개 |

- 탭이나 목록을 바꾸면 `vendorItemId`와 제목이 바뀌고 `productId`는 그대로였다. 예: 988704 900ml 1개 3000080376 → 3개 84994382771 → 500ml 탭 2개 3000992209.
- 목록 항목마다 묶음 가격이 따로 있다(카놀라유 900ml 1개 4,380원, 2개 7,760원 '2개 사면 1,000원 절약'). 탭마다 목록 항목이 다르다.
- 표시 단위가격은 탭 값 × 목록 개수 기준이다. 두부 520g 4개 10,200원 '(100g당 490원)' = 10,200 ÷ 2,080g × 100.
- 담기 버튼 옆 수량 버튼은 선택한 옵션을 몇 개 담을지이고 옵션과 별개다(§6.4).
- 같은 제목의 상품이 서로 다른 `productId`로 등록되어 있다. 수집 검색 결과(`scripts/llm_eval/data*`)에서 제목(첫 쉼표 앞) 223개 중 10개가 `productId` 2개 이상이었다. 해표 카놀라유 500ml 1개는 9737060662(`vendorItemId` 3000014846)와 988704(94627340359)에 따로 있었다.

### 6.6 `itemId`와 판매자 (2026-10-29, 비로그인)

- 상품 페이지 데이터 안의 쿠팡 주소가 `/vp/products/{productId}/items/{itemId}/vendoritems/{vendorItemId}/…` 모양이다. 해표 카놀라유 900ml 1개는 `productId` 988704, `itemId` 18877618217, `vendorItemId` 3000080376이다.
- 같은 데이터에서 이 옵션('해표 카놀라유, 900ml, 1개')의 `otherSellerCount`는 25였다. 화면에는 판매자 '쿠팡(주)'만 보였고 다른 판매자 목록은 찾지 못했다. 페이지가 부르는 `/vm/v5/products/988704/vendor-items/{vendorItemId}`를 같은 출처로 다시 부르면 200·빈 응답이었다.
- 같은 `itemId` 아래 다른 `vendorItemId`를 직접 보지는 못했다.
- 같은 `productId` 988704 안에 다른 판매자(모두야)의 옵션이 있었다. `vendorItemId` 82852630442, `itemId` 28979329392, 제목 '해표 카놀라유 500ml*2병(10세트/1박스) 오일선물세트 … 명절선물세트, 1L, 10세트', 85,000원. 쿠팡(주)의 옵션들과 제목의 첫 쉼표 앞이 다르다.

### 6.8 상품명으로 용량을 계산해 쿠팡 단위가격과 대조한 결과 (2026-10-29)

수집 검색 결과 중 단위가격 표시가 있는 상품명 353개에 아래 계산을 적용했다.

- 상품명을 첫 쉼표로 나눠 앞을 상품명, 뒤를 옵션 이름으로 본다.
- 기준 용량(g·kg·ml·L·구)을 옵션 이름에서 하나 찾고, 없으면 상품명에서 하나 찾는다. 못 찾거나 둘 이상이면 계산하지 않는다.
- 기준 용량에 옵션 이름의 개수(개·개입·입·팩·봉·병·박스·세트)를 곱한다.
- `표시 가격 ÷ 용량`을 단위가격 표시의 기준 수량으로 바꿔 표시 금액과 비교한다.

| 결과 | 개수 |
|---|---|
| 2% 이내 | 343 |
| 2% 넘게 다름 | 3 |
| 용량을 계산하지 못함 | 6 |
| 단위 계열이 달라 비교하지 못함 | 1 |

- 옵션 이름이 '1개'·'2개'뿐이고 단위가격이 g·ml 기준인 상품이 16개였다(예: '양파 1kg, 1개' 2,630원 '100g당 263원'). 상품명의 용량으로 계산하면 12개가 2% 이내였다.
- 2% 넘게 다름: '(짓다팜)햇양파 국내산양파 창녕양파 1kg, 1개' 4,200원 '100g당 140원'(계산 420원), '대파1단-약 900g, 1개' 2,720원 '100g당 272원'(계산 302원), '의령농산 … 절단대파, 국내산 절단대파 200g, 1개' 5,600원 '100g당 1,120원'(계산 2,800원, §6.7).
- 계산하지 못함: 상품명에 용량이 여럿('국산 대파 흙대파 1kg 3kg 5kg, 1개', '(당일경매) … 대파 2kg 3kg 5kg 10kg내외 …, 1개', '무항생제 계란 신선한 초란 30구 60구 오픈특가, 1개'), 계란 무게 설명이 함께 잡힘('[양계장사람들] 대란(L 52~59g) … 30구, 1개' 외 1개), 용량 표기 없음('청정원 카놀라유, 1개' '1세트당 4,810원').
- 비교하지 못함: '매일농장 매일계란 … 30구, 1개, 2kg 내외' '1구당 430원'(옵션 이름의 2kg과 '구').
- 단위가격 표시의 기준 수량은 이 데이터에서 100g·1구·100ml·10ml·1세트였다.
