# 쿠팡 페이지 실동작 확인

> 대상: 사주라 확장이 쿠팡에서 읽고 수행해야 하는 동작(`04_fe.md` §12)이 실제 페이지에서 가능한지. 2026-10-28, 데스크톱 Chrome, 비로그인 상태에서 확인했다.

---

## 1. 검색 결과 페이지 (`/np/search?q=<검색어>`)

- 상품 카드는 `li.ProductUnit_productUnit__Qd6sv`다. 클래스 이름 뒤 해시(`__Qd6sv`)는 빌드마다 바뀔 수 있는 CSS 모듈 형식이다.
- 카드 링크는 `/vp/products/<productId>?itemId=<itemId>&vendorItemId=<vendorItemId>&…`다. 카드의 `data-id` 속성 값은 `vendorItemId`와 같다(60개 중 60개).
- 카드 글자에 상품명(용량·개수 포함), 취소선 가격, 할인율, 표시 가격, 단위가격 표시가 있다. 예: '구이용 삼겹살, 1kg, 2개 / 38,500원 / 48% / 19,900원 / (100g당 995원)'.
- 취소선 가격 요소의 클래스에 `fw-line-through`가 있다.
- 단위가격 표시는 표시 가격 기준이다. 예: 29,500원 ÷ (500g × 4) × 100g = 1,475원과 표시 '(100g당 1,475원)'이 일치한다.
- 한 페이지 60개 카드 중 광고 카드가 있고('광고' 글자), 같은 상품이 광고와 일반 결과에 두 번 나온다(삼겹살: 60개 중 고유 `vendorItemId` 54개, 광고 10개).
- '와우 가입 쿠폰'처럼 표시 가격 아래에 별도 금액이 붙는 카드가 있다(삼겹살 60개 중 5개).
- 취소선 가격이 표시 가격보다 크게 높은 카드가 있다. 예: '[10박스한정] 삼겹살 1kg' 취소선 67,200원, 할인율 75%, 표시 가격 16,800원.

### 검색어별 집계 (각 60개 카드)

| 검색어 | 취소선 있음 | 단위가격 기준 |
|---|---|---|
| 삼겹살 | 55 | 100g 60 |
| 계란 | 27 | 1구 56, 표시 없음 4 |
| 식용유 | 45 | 100ml 60 |
| 원두 | 38 | 10g 60 |
| 소주 | 36 | 100ml 54, 10ml 1, 1세트 2, 표시 없음 3 |
| 양파 | 42 | 100g 60 |

## 2. 연속 검색

- 검색 페이지에서 같은 출처 `fetch('/np/search?q=…')`로 다섯 검색어를 연달아 요청했다. 모두 200, 각 약 1.0~1.2초, 응답 HTML 0.8~1.6MB였고 차단·확인 페이지는 없었다.
- 받은 HTML을 `DOMParser`로 읽으면 화면과 같은 상품 카드 60개가 들어 있다. 탭을 열지 않고도 검색 결과를 읽을 수 있다.
- 다섯 번보다 많은 연속 요청과 짧은 간격의 반복은 확인하지 않았다.
- 같은 브라우저에서 약 10분 동안 위 fetch 5회, 상품 페이지 2개 열기, 장바구니 담기 1회, 장바구니 페이지 열기를 한 뒤, 새 탭에서 검색 페이지 주소(`/np/search?q=삼겹살`)를 직접 열자 '요청하신 페이지의 사용권한이 없습니다' 페이지(참조 번호 포함)가 나왔다. 첫 검색 페이지도 같은 방식(주소 직접 열기)으로 열었을 때는 정상이었다. 차단이 주소 직접 접근 때문인지 그 사이 활동이 쌓인 때문인지는 이 관찰로 나눌 수 없다.

## 3. 상품 페이지 (`/vp/products/<productId>?itemId=…&vendorItemId=…`)

- 가격 영역은 `.price-container`이고, `.original-price`에 할인율·취소선 가격, `.final-price`에 표시 가격과 단위가격 표시가 있다.
- 묶음 수량(1개·2개·3개…)이 선택지로 나오는 상품이 있다. 선택지마다 가격이 다르다.
- 로켓프레시 상품(모아미트 삼겹살 1kg)은 비로그인 상태에서 '장바구니 담기' 대신 '로켓와우 신청하기' 버튼만 보인다.
- 판매자 배송 상품(친절정육점 벌집 삼겹살)은 `button.prod-cart-btn`('장바구니 담기')과 `button.prod-buy-btn`('바로구매'), 그 옆 수량 입력칸(`input[type=text]`, 기본값 1)이 있다.

## 4. 장바구니 담기

- 판매자 배송 상품에서 수량 입력칸에 2를 넣고 '장바구니 담기'를 누르자 '상품이 장바구니에 담겼습니다' 팝업이 떴고, 장바구니(`cart.coupang.com/cartView.pang`)에 수량 2·31,300원으로 들어갔다.
- 담기 때 `POST /next-api/order/add-cart`가 200으로 응답했고, 이어서 `GET /n-api/web-adapter/cart-count`가 호출됐다.
- 비로그인 상태에서 담은 장바구니는 로그인하면 계정 장바구니로 합쳐진다(사용자 직접 확인).
